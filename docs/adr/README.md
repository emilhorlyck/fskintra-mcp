# Architecture Decision Records

Numbered, immutable records of decisions with non-obvious tradeoffs — the ones
future-me would otherwise re-derive. Format: `NNNN-short-title.md`.

A decision earns an ADR only when all three hold: it is (1) technical, (2) a
choice between real alternatives with non-obvious tradeoffs, and (3) something a
future reader would otherwise have to reconstruct. Skip bug fixes, copy edits,
and one-off scripts.

Much of the existing rationale still lives narratively in
[`../architecture.md`](../architecture.md); migrate a decision here when it needs
to be cited, revisited, or contradicted. When new work contradicts an ADR, say
so explicitly rather than silently overriding it.
